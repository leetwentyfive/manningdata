Predicting Major League Baseball Outcomes Based on Which Team Scores First

Overview

Scoring first in Major League Baseball has long been viewed as an important advantage, but how much does it actually influence the outcome of a game? This project analyzes more than 65,000 historical MLB games to evaluate how the timing of the first run, score differential, and home field advantage affect win probability.

Research Questions

  • How often does the team that scores first win?
  • How does inning influence win probability?
  • How does run differential change those probabilities?
  • Can machine learning models accurately estimate those probabilities?

Tools & Technologies

  • Python
  • pandas
  • NumPy
  • scikit-learn
  • Matplotlib
  • Tableau

Key Findings

  • The team that scores first wins approximately two-thirds of MLB games.
  • Early scoring provides a measurable advantage, but win probability depends heavily on inning and run differential.
  • Machine learning predictions were cautious in the early innings but increasingly reflected historical expectations as games progressed.
